# Experiments

Benchmarks and tests for the tensor network MPS decoder on QLDPC codes.

## Environment Setup

### Prerequisites

- Python >= 3.11
- [uv](https://docs.astral.sh/uv/) package manager

### Create virtual environment and install dependencies

```bash
# Install uv (if not already installed)
curl -LsSf https://astral.sh/uv/install.sh | sh
source $HOME/.local/bin/env

# Create venv with Python 3.12
uv venv .venv-mps --python 3.12

# Install core dependencies
uv pip install --python .venv-mps/bin/python \
    numpy scipy quimb autoray matplotlib pytest

# Install decoder dependencies
uv pip install --python .venv-mps/bin/python \
    ldpc stim PyMatching cotengra

# (GPU only) Install cupy and cudaq
uv pip install --python .venv-mps/bin/python cupy-cuda12x cudaq
```

### Verify installation

```bash
.venv-mps/bin/python -c "import quimb; import numpy; print('OK')"
```

## Running Tests

All tests use the `cudaq_qec` Python package from the local `cudaqx/` tree. Set `PYTHONPATH` accordingly:

```bash
export PYTHONPATH=cudaqx/libs/qec/python:.
```

### Task 2: Multi-decoder benchmark

Compares MPS-TN, exact TN, BP, BP-OSD, and BP-LSD decoders on BB and HP codes.

```bash
# As pytest
.venv-mps/bin/python -m pytest experiments/tests/test_multi_decoder_benchmark.py -v -s

# Standalone (full benchmark, more shots)
.venv-mps/bin/python experiments/tests/test_multi_decoder_benchmark.py
```

### Task 4: Chi (bond dimension) sweep

Sweeps chi values `[2, 4, 8, 16, 32, 64]` measuring logical error rate and decode latency.

```bash
# Smoke test (chi=4,8, 8 shots)
.venv-mps/bin/python -m pytest experiments/tests/test_chi_sweep.py -v -s

# Full sweep (64 shots, all chi values)
.venv-mps/bin/python experiments/tests/test_chi_sweep.py
```

### Task 5: GPU metrics profiling

Profiles compile time, decode latency, and (on GPU) memory/utilization via pynvml.

```bash
# Smoke test
.venv-mps/bin/python -m pytest experiments/tests/test_gpu_metrics.py -v -s

# Full profiling
.venv-mps/bin/python experiments/tests/test_gpu_metrics.py
```

### Run all tests at once

```bash
.venv-mps/bin/python -m pytest experiments/tests/ -v -s
```

### Decoder comparison (full experiment)

```bash
# Run with a config file
.venv-mps/bin/python experiments/run_decoder_comparison.py \
    --config experiments/configs/qldpc_six_codes.yaml

# Summarize results to markdown/CSV
.venv-mps/bin/python experiments/summarize_decoder_comparison.py
```

## Decoder Backends

The MPS decoder (`tensor_network_mps_decoder`) uses three backends in priority order:

1. **OneDChainMPS** -- 1D chain extraction (surface/toric codes)
2. **CompressedTNDecoder** -- fully contracted MPS for QLDPC codes where 1D chain topology is unavailable
3. **Exact contraction fallback** -- full TN contraction via cutensornet (GPU) or torch (CPU)

For QLDPC codes (BB, HP), the CompressedTNDecoder is the primary online decode path (~0.3ms/shot on CPU).
